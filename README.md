# Bladebound Duo / 刃誓双雄

一款原创的双人同屏像素风横版动作游戏。项目受到经典街机清版动作游戏的启发，但角色、世界观、画面与代码均为原创。

## 立即游玩

这是一个零依赖静态网页项目。直接打开 `index.html` 即可，或在项目目录运行：

```bash
python3 -m http.server 8080
```

然后访问 <http://localhost:8080>。

## 操作

| 玩家 | 移动 / 跳跃 | 攻击 | 闪避 |
| --- | --- | --- | --- |
| P1 | `W` `A` `S` `D` | `F` | `G` |
| P2 | 方向键 | `K` | `L` |

- `Enter`：开始 / 暂停
- 标题界面按左右方向键：切换单人或双人模式
- 游戏会自动暂停，避免切换窗口时遭到攻击

## 已实现内容

- 单人和本地双人同屏模式
- 四波渐进战斗与原创 Boss“裂岩守卫”
- 铁刃、日矛和岩锤三种武器，带攻击距离、伤害和耐久差异
- 生命、复活、连击、分数、掉落与治疗机制
- 跳跃、闪避无敌帧、击退、屏幕震动和粒子反馈
- 程序化像素场景、角色与 Web Audio 音效，不依赖外部素材
- 响应式页面布局与键盘可访问性

## 技术栈

- HTML5 Canvas
- 原生 JavaScript
- CSS
- Web Audio API

无需构建步骤，也没有第三方运行时依赖。
